# UI experiments

No experiment yet. Belongs here: components and compositions that are not yet in `@krizaka/ui`.

Add one with `experiments/ui/<name>/README.md` ([template](../TEMPLATE.md)): what it tests, its status
(`idea`, `prototype`, `promoted`, `dropped`) and the issue or ADR it feeds. An experiment that proves itself is
promoted into a real package by an ADR; nothing outside the lab imports from here.
