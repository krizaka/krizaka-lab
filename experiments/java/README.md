# Krizaka Java experiments

No experiment yet. Belongs here: a building block, a Spring slice, a build trick, a test technique.

Add one with `experiments/java/<name>/README.md` ([template](../TEMPLATE.md)): what it tests, its status
(`idea`, `prototype`, `promoted`, `dropped`) and the issue or ADR it feeds. An experiment that proves itself is
promoted into a real package by an ADR; nothing outside the lab imports from here.
