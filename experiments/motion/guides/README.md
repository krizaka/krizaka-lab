# The motion guides

- **Area:** motion
- **Status:** prototype
- **Feeds:** https://ui.krizaka.com/docs/foundations/motion
- **Where it lives:** `src/lab/guides.ts`, thirteen routes (`/list-arrival`, `/live-number`, `/page-transition`...)

## What it tests

One motion task per guide, played on a real app screen made of `@krizaka/ui`, with its settings and the code to copy.

## Result

Each guide says what happens under reduced motion. The generic ones become `@krizaka/ui/motion` pieces.
