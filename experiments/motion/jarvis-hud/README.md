# Holographic HUD

- **Area:** motion
- **Status:** prototype
- **Feeds:** https://github.com/krizaka/krizaka-lab/blob/main/docs/adr/ADR-001-reference-motion-library.md
- **Where it lives:** `src/core/jarvis-hud.ts`, route `/jarvis`

## What it tests

Rings, reticles and telemetry with a gyroscope's parallax: how dense, legible motion can look on a canvas.

## Result

A study. Paused off screen, one still frame under reduced motion. No Krizaka site uses canvas, so nothing is promoted.
